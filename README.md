# Fake News Detection System

AI-powered Fake News Detection using:
- Machine Learning
- NLP
- Streamlit
- LIME Explainable AI

## Features
- Detects Fake and Real News
- Multiple ML Models
- Accuracy Comparison Graphs
- Explainable AI using LIME
- Streamlit Web Interface

## Technologies Used
- Python
- Scikit-learn
- NLTK
- Streamlit
- Matplotlib
- Seaborn

## Run Project

```
streamlit run src/main.py
```
## Result

The Fake News Detection System successfully classifies news articles as:
- REAL NEWS 
- FAKE NEWS 

The project was tested using multiple Machine Learning algorithms:
- Logistic Regression
- Naive Bayes
- Support Vector Machine (SVM)
- Random Forest

Among all models, Random Forest and SVM achieved the highest accuracy on the dataset.

The system also generates:
- Accuracy comparison graphs
- Performance metric graphs
- Confusion matrix visualization
- Explainable AI output using LIME

The Streamlit interface provides an interactive and user-friendly environment for real-time prediction and analysis.

## Conclusion

The Fake News Detection System demonstrates how Machine Learning and Natural Language Processing can be used to identify misinformation effectively.

The project:
- Automates fake news classification
- Reduces manual verification effort
- Improves awareness about misinformation
- Provides explainable predictions using LIME Explainable AI

By combining NLP, ML models, visualization techniques, and a Streamlit web interface, the system becomes a practical and efficient solution for fake news detection.
